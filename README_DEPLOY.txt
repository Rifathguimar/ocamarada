Conteúdo:
- /inquerito/index.html: inquérito interactivo completo
- /index.html: página mínima de entrada

Para publicar no domínio ocamarada.ao é necessário acesso ao alojamento/DNS do domínio.
Em Vercel, publique a pasta inteira como projecto estático e associe o domínio ocamarada.ao.
Se ocamarada.ao já estiver alojado noutro serviço, publique apenas a pasta /inquerito nesse servidor ou configure um reverse proxy/route para este projecto.
